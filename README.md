# **R**everse **E**ngineered **S**ource (**RES**)

The **RES** architecture is an information storage template designed to ease the documenting process for any form and amount of systemic unknowns.

To learn how to use the template, see [[getting-started]]. To learn how it's organized, see [[layout]], and to learn how pages should be written, see [[standards]].
